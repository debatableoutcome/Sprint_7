
# Sprint_7 — API тестирование сервиса Яндекс Самокат

Учебный проект 7 спринта.  
В проекте реализованы автотесты для REST API сервиса Яндекс Самокат с использованием `pytest`, `requests` и `Allure`.

Тесты проверяют корректность работы основных и дополнительных ручек API, а также обработку ошибок.

---

## Используемый стек

- Python
- pytest
- requests
- allure-pytest

## Что протестировано

### Основное задание

**Курьеры**
- создание курьера
- невозможность создания дубликата
- ошибки при отсутствии обязательных полей
- логин курьера
- ошибки при неверных данных и несуществующем пользователе

**Заказы**
- создание заказа:
  - с цветом BLACK
  - с цветом GREY
  - с двумя цветами
  - без указания цвета
- проверка наличия `track` в ответе
- получение списка заказов

---

### Дополнительное задание

- удаление курьера
- принятие заказа курьером
- получение заказа по номеру (`track`)
- проверки ошибок при отсутствии и неверных параметрах
- использование query-параметров

---

## Принципы тестирования

- каждый тест независим
- тестовые данные создаются перед тестом
- тестовые данные удаляются после теста
- проверяется HTTP-код ответа и тело ответа
- для очистки данных используется `finally` или teardown фикстур
- JSONDecodeError обработан через безопасный парсер ответа

---

## Запуск тестов

### Установка зависимостей

```bash
pip install -r requirements.txt
````

### Запуск всех тестов

```bash
pytest
```

---

## Allure-отчёт

Результаты тестов сохранены в папке:

```
target/allure-results
```

Для генерации отчёта:

```bash
allure serve target/allure-results
```

В репозиторий добавлена **только папка с результатами** без лишних файлов
